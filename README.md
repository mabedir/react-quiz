# React Quiz Application

This project is part of the Jonas React Course and is developed to understand the useReducer hook in React. The application is a quiz that tests your knowledge of React concepts.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in interactive watch mode.\
See the section about [running tests](https://facebook.github.io/create-react-app/docs/running-tests) for more information.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

### `npm run eject`

**Note: this is a one-way operation. Once you `eject`, you can't go back!**

### `npm run server`

Starts the JSON server to serve the quiz questions.\
Open [http://localhost:8000/questions](http://localhost:8000/questions) to view the questions in your browser.

## Project Structure

- `src/components`: Contains all the React components used in the application.
- `data/questions.json`: Contains the quiz questions.
- `public`: Contains the public assets and HTML file.

## Key Concepts

- **useReducer Hook**: This project demonstrates the use of the `useReducer` hook to manage complex state logic in React.
- **Component Structure**: The application is divided into multiple components, each responsible for a specific part of the UI.

## How to Use

1. Clone the repository.
2. Run `npm install` to install the dependencies.
3. Run `npm start` to start the React application.
4. Run `npm run server` to start the JSON server for quiz questions.

Enjoy the quiz and enhance your React knowledge!
